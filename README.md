# ملصقات برو — النسخة الكاملة

## ماذا تحتوي؟
- واجهة زبون احترافية RTL.
- اختيار الأحجام والكميات وحساب السعر.
- رفع عدة صور مع معاينة.
- إرسال الطلب إلى الخادم.
- تخزين الطلبات والزبائن والأسعار في `data/db.json`.
- رفع الصور إلى `uploads/`.
- لوحة مدير منفصلة على `/admin`.
- تسجيل دخول للمدير.
- إحصائيات الطلبات والإيرادات والملصقات.
- البحث في الطلبات.
- تغيير حالة الطلب: قيد الانتظار / قيد الطباعة / مكتمل / ملغى.
- عرض صور الطلب.
- طباعة ورقة الطلب.
- إدارة الأسعار من لوحة المدير.
- تصميم متجاوب للهاتف والكمبيوتر.

## التشغيل
تحتاج Node.js حديثاً.

1. افتح Terminal داخل مجلد المشروع.
2. نفذ:
   `npm install`
3. ثم:
   `npm start`
4. افتح:
   `http://localhost:3000`
5. لوحة المدير:
   `http://localhost:3000/admin`

## كلمة مرور المدير الافتراضية
`admin123`

يمكن تغييرها قبل التشغيل:
Windows PowerShell:
`$env:ADMIN_PASSWORD="كلمة-مرور-جديدة"; npm start`

Linux/macOS:
`ADMIN_PASSWORD="كلمة-مرور-جديدة" npm start`

## ملاحظة مهمة
هذه نسخة محلية كاملة مناسبة كبداية للمشروع. قبل نشرها على الإنترنت، يجب إضافة قاعدة بيانات حقيقية، HTTPS، نظام مستخدمين أقوى، حماية CSRF/rate limiting، ونسخ احتياطية للصور والبيانات.


## الميزات المضافة
- معاينة صور كل طلب داخل لوحة المدير قبل تحميلها، مع زر تحميل مستقل.
- إنشاء إشعارات وعروض وتخفيضات من لوحة المدير.
- تحديد نوع الإشعار وتاريخ انتهائه.
- إظهار الإشعارات تلقائياً في صفحة الزبون مع إمكانية إخفائها.
- إضافة منتجات وأسعار جديدة.
- تعديل أسعار المنتجات الحالية.
- حذف المنتجات من لوحة المدير.
- زر لوحة المدير غير ظاهر في واجهة الزبون؛ صفحة المدير محمية بتسجيل الدخول.


## نظام العروض التلقائي
يمكن للمدير إنشاء عرض مع كود وخصم نسبة مئوية أو مبلغ ثابت وحد أدنى للطلب.
عند ضغط الزبون على بطاقة العرض، ينتقل مباشرة إلى منطقة العرض ويتم حفظ العرض المختار.

- إلغاء الإشعار أو العرض مؤقتاً دون حذفه، مع إمكانية تفعيله لاحقاً.
- حذف الإشعار نهائياً من لوحة المدير.
